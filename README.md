# Kismet Install

Installs [Kismet](https://www.kismetwireless.net/) on Ubuntu 24.04 (noble) the way the
[Kismet Linux install documentation](https://www.kismetwireless.net/docs/readme/installing/linux/)
describes, and runs it as a systemd service.

| File | Purpose |
|------|---------|
| `detect-devices` | Optional, run first. Finds Wi-Fi, Bluetooth and USB radios Kismet can use and writes `kismet-sources.list`. No root needed. |
| `install-kismet` | Installs Kismet and sets up the `kismet.service` systemd unit. Run with `sudo`. |
| `kismet-sources.list` | Generated by `detect-devices`. One Kismet data source per line; `#` lines are ignored. |

## Quick start

```bash
./detect-devices          # review the report and kismet-sources.list
sudo ./install-kismet
```

Then browse to `http://<host>:2501/` and set the admin password on the first visit.
The web UI listens on all interfaces, so do this promptly.

## What `install-kismet` does

1. Adds the official Kismet apt repository and signing key.
2. Installs `kismet` with the capture helpers set up for the `kismet` group
   (the "suid-root helpers" debconf answer). Kismet itself does not run as root.
3. Creates a `kismet` system user (no login shell, home `/var/lib/kismet`) in the `kismet`
   group and in `plugdev`. USB radios such as RTL-SDR and Ubertooth are `root:plugdev`
   through their udev rules, so the service needs that group.
4. Adds the sources from `kismet-sources.list` and `KISMET_SOURCES` to
   `/etc/kismet/kismet_site.conf`. Lines already present are skipped.
5. Writes `/etc/systemd/system/kismet.service`, then enables and starts it.

The script is safe to re-run. `NoNewPrivileges` is deliberately not set in the unit,
because it would stop the setuid capture helpers from working.

### Options

Set these as environment variables, passed after `sudo`:

```bash
sudo KISMET_SOURCES="wlx00c0caa6850f:name=alfa" ./install-kismet
```

| Variable | Default | Meaning |
|----------|---------|---------|
| `KISMET_USER` | `kismet` | Service account |
| `KISMET_HOME` | `/var/lib/kismet` | Working directory; logs (`*.kismet`) are written here |
| `KISMET_SOURCES` | none | Space-separated extra data sources |
| `KISMET_ADMIN` | the invoking user | Extra login(s) added to the `kismet` group so they can run Kismet by hand |

## Data sources

Sources added in the web UI take effect immediately but are **not saved**; they are gone
after a service restart or reboot. To make a source permanent, add a line to
`/etc/kismet/kismet_site.conf` and restart:

```bash
echo 'source=wlx00c0caa6850f:name=alfa' | sudo tee -a /etc/kismet/kismet_site.conf
sudo systemctl restart kismet
```

An RTL-SDR dongle can run only one of `rtl433` or `rtladsb`. `detect-devices` writes both
commented out; uncomment the one you want.

## Day to day

```bash
systemctl status kismet
journalctl -u kismet -f
sudo systemctl restart kismet
```

## Troubleshooting

| Symptom in the log | Cause and fix |
|--------------------|---------------|
| `status=217/USER` | The service user does not exist. Re-run `install-kismet`. |
| `libUSB Error: Access denied` | The `kismet` user is not in `plugdev`, or the service was not restarted after it was added. Run `sudo usermod -aG plugdev kismet && sudo systemctl restart kismet`. |
| `Could not acquire the interface lockfile (Operation not permitted)` | A stale `/tmp/.kismet_cap_linux_wifi_interface_lock` was left by a manual run as another user. Run `sudo rm -f /tmp/.kismet_cap_linux_wifi_interface_lock` and restart. |
| Wi-Fi source fails and a `kismon0` interface exists | A leftover monitor interface from a manual run. Run `sudo ip link delete kismon0` and restart. |

If you run `kismet` by hand as your own user later, stop the service first. Delete the
lockfile above afterwards, or the service will hit the same error.

## Notes

- Written for Ubuntu 24.04; the script warns on other releases.
- `detect-devices` recognises RTL-SDR (RTL2832/2838), Ubertooth One, bladeRF, HackRF (reported only),
  TI CC25xx dongles, Wi-Fi interfaces and Bluetooth adapters. Anything else needs a source added by hand;
  see the Kismet documentation.
